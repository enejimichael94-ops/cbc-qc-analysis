# Basic CBC Quality Control Analysis

A Python script using `pandas` and `matplotlib` to clean synthetic automated hematology analyzer data, handle missing values, calculate batch statistics, and visualize hemoglobin outliers.

## Clinical Limitations & Disclaimer
**This tool processes synthetic data for educational purposes only.** It is not clinically validated and strictly must not be used for patient-care, medical screening, or diagnostic decisions.

## Usage
This script is designed to run in a Python environment like Google Colab. It requires the `pandas` and `matplotlib` libraries.
